> [!info] How this vault is maintained
> - **Automatic:** Claude Code hooks append every prompt, file edit, command and final reply to `80 Logs/YYYY-MM-DD.md`; every delegated Codex run becomes a note in `60 Agents/Codex runs/`.
> - **Curated:** after each meaningful step Claude updates [[Status]], the phase note, decisions, findings and the day's session journal (rules: `CLAUDE.md` §13).
> - Raw logs are local (git-ignored); curated notes are versioned with the code.
